# 세븐틴 매드무비 프롬프트 — 클로드 코드에 그대로 붙여 넣기

맥에서 빈 폴더를 하나 만들고 클로드 코드(Opus 5.5)를 연 뒤, 아래 상자 안 전체를 붙여 넣는다.
뼈대는 빈 폴더 테스트를 통과한 매드무비 프롬프트(`lectures/003-mad-movie/prompt.md`)와 같다. 소스·곡·효과 몇 개만 세븐틴 영상에 맞게 바꿨다.

```text
너는 모션 디자이너이자 영상 편집자야. 세븐틴 공식 'Anyone' 스페셜 비디오로 17초짜리 매드무비를 처음부터 끝까지 만들어 줘.
매드무비 = 음악 박자에 맞춰 영상을 자르고, 사람 누끼·큰 글자·효과를 얹은 짧은 영상.
영상 편집 앱은 쓰지 않는다. 전부 코드로 만든다: 장면은 HTML 한 장, 프레임은 헤드리스 크롬으로 한 장씩 찍고, ffmpeg로 영상을 만든다.
가로(1920×1080)와 세로 쇼츠(1080×1920) 두 개를 만든다.

[0. 작업 환경]
- 이 폴더 안에서만 작업해. 맥(Apple Silicon) 기준이야.
- 필요한 것: Node 18 이상, Python 3 + numpy, ffmpeg, Google Chrome, swiftc(Xcode Command Line Tools). 없으면 설치 방법을 알려 줘.
- 헤드리스 크롬은 puppeteer-core로, 맥에 설치된 Chrome을 쓴다(크롬을 따로 내려받지 않는다).
- 애매한 건 멈추지 말고 합리적인 기본값으로 진행하고, 마지막에 무엇을 골랐는지 알려 줘.

[1. 소스 — 위키미디어 공용의 CC BY 파일]
- 세븐틴 공식 유튜브 채널은 영상 대부분을 CC BY(크리에이티브 커먼즈 저작자 표시)로 올린다. 출처를 밝히면 편집·재배포가 허용된다.
- 유튜브에서 직접 내려받지 않는다(유튜브 약관 위반). 같은 영상이 위키미디어 공용에 원본 화질로 올라와 있으니 거기서 받는다.
  · 파일: https://commons.wikimedia.org/wiki/File:(SPECIAL_VIDEO)_SEVENTEEN(세븐틴)_-_Anyone.webm
  · 3840×2160, 23.976fps, 3분 43초, 464MB, CC BY 3.0. 원본 주소는 공용 API(action=query&prop=videoinfo&viprop=url)로 얻는다. User-Agent를 붙인다.
- 영상 끝과 설명란에 출처를 적는다: "영상: SEVENTEEN 'Anyone' Special Video (CC BY 3.0) · 편집함" + 원본 링크. 공식 영상처럼 보이게 만들지 않는다.
- CC BY는 초상권까지 풀어 주지 않는다. 광고·굿즈에는 쓰지 않는다.

[2. 박자 — 곡에서 직접 잰다]
- 곡의 BPM과 박 위치를 numpy로 잰다: 스펙트럴 플럭스 온셋 곡선 → 자기상관으로 BPM → 곡 전체에 박 간격 빗을 대 보며 위상을 맞춘다.
- 마디 첫 박은 박별 음량이 크게 바뀌는 박(4로 나눈 나머지)으로 고른다. 후렴·브레이크 같은 구간 경계가 마디 첫 박에 떨어져야 맞다.
- 우리가 잰 값(검산용): 110 BPM, 1박 = 0.54545초(30fps에서 16.3636프레임), 첫 박 0.32초. 박마다 킥이 들어가는 곡이라 박 위 음량이 확 크다.
- 쓸 구간: 2:12.32부터 8마디(32박 = 17.4545초 = 524프레임).
  · 1마디(2:12.32) 인트로 — 킥이 3박 치고 브레이크 시작
  · 2마디(2:14.50) 라이저 — 킥이 빠진 브레이크, 마지막 박 앞에 한 번 치고
  · 3마디(2:16.68) 드롭 — 킥이 다시 들어온다. 여기서 터진다
  · 3~7마디 드롭 5마디, 8마디 엔딩
- 프레임 f가 몇 번째 박인지는 매번 floor(f / 30 / 0.54545)로 계산한다. 시간을 더해 가며 세면 뒤로 갈수록 박이 밀린다.

[3. 음악 — 같은 영상의 곡을 그대로]
- 음악은 합성하지 않고, 같은 CC BY 파일의 곡을 쓴다. 2:12.32부터 17.4545초를 잘라 끝 0.6초는 페이드아웃, 시작은 0.01초 페이드인(딸깍 소리 방지).
- 실제 곡이라 음악을 비우는 효과는 넣지 않는다. 브레이크가 원래 곡에 있다.

[4. 프레임과 누끼]
- 프레임: 곡보다 1초 앞(2:11.32)부터 19.5초를 30fps JPG로 뽑는다(원본은 23.976fps라 일부 프레임이 겹친다). 가로는 1920×1080, 세로는 4K 원본 가운데를 9:16으로 잘라 1080×1920.
  · ffmpeg는 기본이 00001부터라 번호를 헷갈리지 않게 한다.
- 누끼: Swift 커맨드라인 도구를 만든다. 프레임 폴더를 받아 사람만 남긴 투명 PNG 폴더를 만든다. 크기는 원본과 같게.
  · 사람 모드: VNGeneratePersonSegmentationRequest, qualityLevel = .accurate
  · 피사체 모드: VNGenerateForegroundInstanceMaskRequest (macOS 14+, 사진 앱 '피사체 들어올리기' 방식)
  · 둘 다 모드(이번에 쓸 것): 두 마스크 중 밝은 쪽(CIMaximumCompositing). 13명이 멀리 잡힌 장면은 사람 모드가 멤버를 반투명하게 잡거나 통째로 비운다(0%). 피사체 모드가 그걸 채운다.
  · 마스크는 원본 해상도로 키워서 원본 픽셀의 알파로 입히고, 가장자리는 1.5px 부드럽게.
- 다 딴 뒤 장마다 알파 평균을 재서 3% 미만인 장이 없는지 확인하고, 파란 단색 배경에 얹은 콘택트 시트로 멤버가 흐리게 빠진 곳이 없는지 본다.

[5. 디자인 — 1920×1080(세로는 1080×1920), 30fps]
- 레이싱 서킷 영상이라 색도 레이싱으로: 배경 #0b0b0e, 글자 흰색, 강조 4색 #e10600(레이싱 레드) #15151a(블랙) #f2b705(옐로 플래그) #1f4bd8(블루). 강조색은 박마다 돌아가며 쓴다.
- 폰트(Google Fonts):
  · 제목: Anton, "ANYONE"(곡 이름, 영문 6자).
  · 자막: Black Han Sans, 가로 120px(세로 104px), 화면 아래 가운데. 한글 8자 이하, 한 자막은 2박 동안. 글자마다 0.04초 간격으로 아래에서 튀어 오르며 등장(0.6배→1배), 검은 테두리 3px + 그림자.
  · 자막에 가사는 쓰지 않는다(가사는 따로 권리가 있다).
  · 한글 폰트는 실제 자막 글자를 같이 넘겨 로드한다(document.fonts.load('120px "Black Han Sans"', '열세 명 한 몸처럼 칼군무 세븐틴')).
- 레이어 순서(아래→위): 배경 영상·색 → 색 보정 → 흐르는 글자·뒤 글자 → 잔상 → 누끼 → 앞 글자 → 자막 → 흰 플래시.
- 규칙:
  · 한 화면에 효과(잔상·RGB 분리·글리치·흐르는 글자 같은 화면 효과)는 두 개까지만 겹친다. 줌·흔들림·펀치 같은 카메라 움직임은 세지 않는다.
  · 춤과 곡이 어긋나지 않게, 영상은 곡과 같은 시각의 프레임을 쓴다(마디 i는 프레임 30 + i × 65.45부터). 슬로모션 마디만 예외.
  · RGB 분리는 라이저와 박수 박에만, 강한 흰 플래시는 마디 첫 박에만.
  · 박 펀치: 박이 칠 때마다 화면이 1.07배로 커졌다가 곧 돌아온다.
  · 글자가 얼굴을 가리지 않게 한다. 세로는 위아래 15%에 글자를 두지 않는다.
  · 마지막 0.5초는 검은 화면으로 페이드아웃.

[6. 마디별 장면]
1마디 · 인트로 (0~2.18초) — 글자가 하나씩
  - 원본 영상 그대로(싱크 유지). 박마다 밝게 번쩍했다가 어두워진다.
  - 가운데 "ANYONE"(330px)이 박마다 늘어난다: AN → ANY → ANYON → ANYONE. 새 글자는 1.35배에서 1배로 튀며 들어온다.
  - 박마다 화면이 잠깐 흔들리고 약한 플래시.
2마디 · 라이저 (2.18~4.36초) — 브레이크, 멤버 클로즈업
  - 큰 "ANYONE"을 멤버 뒤에 깐다(누끼가 글자 위). 글자는 점점 커진다(420→580px, 세로는 폭에 맞게).
  - 줌(1→1.28배), 흔들림, RGB 분리(최대 40px), 채도가 점점 세진다. 제곱 곡선으로 끝에 몰리게.
  - 마지막 0.15초는 검은 화면. 드롭 직전 암전.
3마디 · 드롭 ① 팝 (4.36~6.55초)
  - 단색 배경이 박마다 강조색으로 바뀐다. 멤버 누끼에 두꺼운 흰 테두리(스티커처럼 6px) + 아래 그림자.
  - 뒤에 "ANYONE ANYONE…" 외곽선 글자(260px) 4줄이 줄마다 반대 방향으로 흐른다(초당 420px).
  - 드롭 첫 박에 강한 흰 플래시.
4마디 · 드롭 ② 잔상 (6.55~8.73초)
  - 원본 영상(채도 조금 올림) 위에 6·12·18프레임 전 누끼를 초록·파랑·보라로 물들여 반투명하게 겹치고(스크린 합성, 불투명도 0.55·0.42·0.3), 지금 누끼를 맨 위에.
  - 자막: "열세 명"(1~2박) → "한 몸처럼"(3~4박).
5마디 · 드롭 ③ 줌 컷 (8.73~10.91초)
  - 소스가 하나라 영상을 바꾸는 대신, 같은 영상을 박마다 1배 ↔ 1.4배로 당겨 컷처럼 보이게 한다(싱크 유지).
  - 2·4박(박수)에 글리치: 화면을 가로 띠 4개로 나눠 좌우로 어긋나게(최대 60px) 하고 RGB 분리. 띠에도 같은 줌을 건다.
  - 컷마다 짧고 약한 플래시.
6마디 · 드롭 ④ 뒤 글자 (10.91~13.09초)
  - 박마다 색조를 0°·40°·-40°·90°로 돌린다. 멤버 뒤에 화면 폭 90%의 외곽선 "ANYONE".
  - 자막: "칼군무" → "세븐틴".
7마디 · 드롭 ⑤ 레터박스 (13.09~15.27초)
  - 절반 속도 슬로모션(이 마디만 싱크 예외). 위아래 검은 띠(가로 130px, 세로 260px)가 0.4초에 걸쳐 들어온다.
  - 가운데 "A N Y O N E"(150px)의 자간이 마디 동안 40px에서 70px로 벌어진다.
  - 마지막 박 끝에서 플래시가 차오르며 엔딩으로 넘어간다.
8마디 · 엔딩 (15.27~17.45초)
  - 어두운 빨강 원형 그라데이션 배경(#3a0a0a → #0b0b0e).
  - 곡 2:29.3 부근, 멤버들이 앞으로 모인 한 프레임의 누끼를 멈춰 세우고 흰 테두리. 뒤에 "ANYONE"(480px)이 0.5초 동안 나타나며 천천히 커진다.
  - 오른쪽 아래 작은 크레딧: video: SEVENTEEN "Anyone" special video (CC BY 3.0) · edited
  - 첫 박에 플래시, 마지막 0.5초 페이드아웃.

[7. 만드는 방식]
- 장면은 HTML 한 장. window.renderFrame(f)가 프레임 번호 f를 받아 그 순간의 화면을 그린다. 가로·세로는 같은 HTML에 크기 설정만 바꾼다.
  · 같은 f에는 언제나 같은 그림. Math.random·Date는 쓰지 않고, 시드 난수만 쓴다.
  · 이미지가 다 로드(decode)된 뒤 찍는다.
- HTML은 로컬 서버로 띄운다(file://은 이미지 로드가 막힌다).
- puppeteer-core로 창을 열고 f = 0~523을 한 장씩 PNG로 찍는다. 나눠서 병렬로 찍을 땐 탭 여러 개 말고 브라우저를 따로 띄운다(안 보이는 탭은 멈춘다).
- ffmpeg: 프레임(30fps) + 잘라 둔 곡 → H.264(yuv420p, crf 18) + AAC → out/svt-mad.mp4, out/svt-mad-v.mp4

[8. 렌더 전에 스토리보드부터]
- 마디마다 첫 박의 정지 화면 8장 + 라이저 암전 직전 1장을 3×3 한 장(storyboard.png)으로 모아서 보여 주고, 내가 OK 하면 전체 렌더한다.
- 볼 것: 누끼 가장자리, 멀리 잡힌 멤버가 빠지지 않았는지, 글자가 얼굴을 가리는지, 글자가 화면 밖으로 나가는지.

[9. 렌더 후 검수]
- ffprobe로 해상도 · 30fps · 17.45초 · 오디오 스트림이 있는지 확인한다.
- 마디 경계 프레임(박 번호 × 16.3636을 올림: 0, 66, 131, 197, 262, 328, 393, 459)을 콘택트 시트로 뽑아 직접 본다. 드롭 첫 프레임에 플래시가 있는지, 컷이 박에 맞는지.
- 문제가 있으면 고치고 다시 렌더한다.
```

## 바꿔 쓰기
- **다른 세븐틴 영상:** 공식 채널 영상 설명란의 '라이선스'가 크리에이티브 커먼즈인지 먼저 본다. 위키미디어 공용에서 영상 제목으로 찾으면 원본 파일이 있는 경우가 많다.
- **구간:** 곡의 브레이크 → 드롭 자리를 찾아 8마디를 고른다. 박별 음량이 한 마디 동안 푹 꺼졌다가 돌아오는 곳이 드롭이다.
- **자막:** 4마디·6마디 자막만 바꾼다(한글 8자 이하, 가사는 쓰지 않는다).

## 직접 해 보니 (2026-09-27, M4 Pro)
- 13명이 멀리 잡힌 장면은 사람 누끼가 통째로 비었다(0%). 피사체 마스크를 합치니 14%로 채워졌다.

- 누끼 586장은 약 50초 걸렸다(두 모드를 같이 돌려서 한 모드의 1.3배).
