# 과제 — 유튜브 채널 '바이브코더' 조회수 진단과 다시 포장하기

## 채널
- 한국어 유튜브 채널 '바이브코더'. 클로드 코드(AI 코딩 도구)로 실제로 만들어 본 것을 강의로 올린다. 2026-09-25 시작, 구독자 9명.
- 강의 하나 = 롱폼 1편(3~8분, 코드로 렌더한 모션그래픽 + 강아지 캐릭터 + AI 음성 나레이션) + 쇼츠 2~7편.
- 쇼츠는 보통 19:00(한국 시간)에 공개.
- 실제 데이터: `data/channel-2026-10-17.json` (2026-10-17 기준, 영상 23편의 제목·길이·업로드 시각·경과일·조회·좋아요·댓글). 롱폼 썸네일 이미지: `data/thumbs/001-longform.png`, `004-longform.png`(가장 잘 된 롱폼), `006-longform.png`.

## 해 줄 것 (결과는 한국어 마크다운)
1. **진단** — 쇼츠와 롱폼 각각 조회수 패턴. 반드시 데이터의 숫자를 근거로. 추측은 추측이라고 적기.
2. **지금 바로 바꿀 것 3가지** (우선순위 순) — 무엇을 → 어떻게 → 기대 효과 → 7일 안에 어떤 숫자로 확인할지.
3. **막힌 영상 다시 포장** (지금 제목은 데이터 그대로):
   - 롱폼 001 (49회) — 새 제목 3개 + 썸네일 큰 글자 문구(3~6단어) + 이유 한 줄
   - 롱폼 006 (55회, 같은 주제 쇼츠 3편은 각 1,200회 안팎) — 같은 형식
   - 쇼츠 004 shorts-2 (39회) — 새 제목 3개 + 영상 첫 1초 화면 문구 + 첫 문장 대사
   - 쇼츠 003 shorts-7 (52회) — 같은 형식
4. **우리가 놓치고 있던 것 1가지** — 위에 없는 것 중 가장 큰 것.

## 규칙
- 유료 도구·유료 서비스·광고비는 제안하지 않는다. 무료로 할 수 있는 것만.
- 데이터에 없는 수치(업계 평균 CTR 등)를 사실처럼 쓰지 않는다. 쓰려면 '일반론'이라고 표시.
- 웹 검색·외부 접속 없이, 주어진 파일만 본다. 다른 파일은 수정하지 않는다.
- 결과 파일 하나만 쓴다(경로는 지시받은 곳). 250줄 이내.
