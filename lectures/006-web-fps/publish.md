# 006 배포 문구

업로드 설정·실제 문구는 `publish.json`이 원본이다. 이 파일은 사람이 읽기 좋게 옮긴 것이다.

## 유튜브 롱폼
**제목 후보**
1. 클로드 코드로 하루 만에 멀티플레이 FPS 게임 만들기 — 게임 서버비 0원 (WebRTC P2P) ← 사용
2. 이런 FPS 게임, 이제 클로드 코드로 직접 만드세요 — 서버비 0원 P2P
3. AI 에이전트 팀이 14시간 만에 만든 FPS — 진짜 판교역에서 총싸움

**썸네일**: `scenes/out/thumb-1.png` (하루 만에 만든 멀티플레이 FPS · 서버비 0원). 다른 각도로 `thumb-2.png`(진짜 판교역)도 있다.

**설명·챕터·태그·고정 댓글**: `publish.json` → `longform`

## 쇼츠 (각도가 다름)
| 편 | 각도 | 제목 |
|---|---|---|
| ① | 결과 | AI로 하루 만에 만든 FPS — 진짜 판교역에서 총싸움 #Shorts |
| ② | 반전 | FPS 게임 서버비 0원? (WebRTC P2P) #Shorts |
| ③ | 가이드 | AI로 게임 만들면 꼭 막히는 4가지 #Shorts |

설명란의 `[롱폼 링크]`는 롱폼을 올린 뒤 실제 주소로 채운다. 쇼츠 링크는 눌리지 않으니 스튜디오에서 '관련 동영상'을 롱폼으로 지정한다.

## 쓰레드 (개인 계정, 캐러셀 5장 첨부, 롱폼 공개 뒤)
> 다들 혼자서 게임을 만들길래, 저도 클로드 코드로 웹 FPS 게임을 만들었습니다.
> 브라우저·폰에서 설치 없이 하는 멀티플레이 총싸움이고, 14시간 · 커밋 150개 남짓 걸렸습니다.
> 만든 방식을 4가지로 정리했습니다🧵

답글 1/~4/ 와 시작 프롬프트 링크는 `publish.json` → `thread.replies`.

## 공개 일정 (10/9 사용자 확인 "올려" → 예약 완료)
- 전부 비공개로 올린 뒤, 확인을 받으면 `publish.json`에 `schedule`을 넣고 `sync youtube`로 예약한다.
- 제안: 롱폼 + 쇼츠① 10/9(목) 19:00 → 쇼츠② 10/10 19:00 → 쇼츠③ 10/11 19:00, 쓰레드 10/9 19:05
