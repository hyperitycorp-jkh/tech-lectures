## 4. 쓰레드 연재 (7개 포스트)
1. Claude Opus 5.5가 영상을 잘 만든다길래 직접 해봤다. 결론부터: 영상 AI가 아니라 "영상을 그리는 코드"를 짠다. 🧵
2. 원리는 단순하다. 영상은 그림 여러 장. renderFrame(f) 함수가 f번째 그림을 그리고, 헤드리스 Chrome이 한 장씩 찍고, ffmpeg가 묶는다.
3. 무료 도구로 스타일 8개를 만들었다. 모션그래픽, 수채화, 3D, 셰이더, 키네틱 타이포, React UI, D3 차트, 픽셀아트. [쇼릴 링크]
4. 제일 놀라웠던 건 실제 앱 홍보 영상. 레포에서 브랜드 색·로고·스토어 문구를 찾아서 20초 세로 영상 3편을 만들었다.
5. 대신 알아서 완벽하진 않다. 에러 없이 돌아도 제목이 겹치고, 폰 화면이 잘리고, 출처에 없는 내용을 붙이기도 했다. 전부 프레임을 눈으로 보고 잡았다.
6. 정리: 글자·데이터·실제 UI가 중요한 영상은 코드 렌더가 압도적. 실사 장면은 생성형 AI와 섞어 쓰는 게 맞다.
